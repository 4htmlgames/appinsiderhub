## 📋 Adımlar

### 1️⃣ GitHub'a Push Et

```bash
# Git başlat (ilk kez)
git init
git add .
git commit -m "SEO optimizasyonu tamamlandı"

# GitHub'a bağlan
git remote add origin https://github.com/4htmlgames/appinsiderhub.git
git branch -M main
git push -u origin main
```

### 2️⃣ GitHub Pages Ayarları

1. GitHub repo'ya git: https://github.com/4htmlgames/appinsiderhub
2. **Settings** → **Pages**
3. **Source:** GitHub Actions seç
4. Kaydet

### 3️⃣ Bekle (2-3 dakika)

GitHub otomatik olarak:
- ✅ Ruby kurar
- ✅ Jekyll build yapar
- ✅ Site'i deploy eder

### 4️⃣ Site Hazır!

```
https://4htmlgames.github.io/appinsiderhub/
```

## 🌐 Custom Domain (Opsiyonel)

Eğer `appinsiderhub.com` domain'in varsa:

1. **Settings** → **Pages** → **Custom domain**
2. `appinsiderhub.com` yaz
3. DNS ayarlarına ekle:
   ```
   A Record: 185.199.108.153
   A Record: 185.199.109.153
   A Record: 185.199.110.153
   A Record: 185.199.111.153
   ```
